# fluent-sdfx API index

Every exported symbol, generated from the source by tools/llms-check; do not edit by hand. Read docs/llms.txt first for the mental model and the traps; use this file to look up a signature or find a symbol you did not know existed. Each entry is the signature followed by the synopsis of the symbol's doc comment. Import paths are `github.com/snowbldr/fluent-sdfx/<package>`; the vector packages are `vec/v3`, `vec/v2`, `vec/p2`, `vec/v3i`, `vec/v2i`.

### solid — 3D solids: primitives, transforms, booleans, blends, patterns, modifiers, anchors, output.

Constants and variables:
- `solid.MinCells` — MinCells is the floor applied by CellsFor so sub-mm parts (e.g. a 1 mm sphere at 3 cells/mm, which would otherwise give 3 cells and render as an empty mesh) still produce a recognizable shape.

Functions:
- `solid.Box(size v3.Vec, round float64) *Solid` — Box returns an axis-aligned box of the given size, centered at the origin.
- `solid.Capsule(height, radius float64) *Solid` — Capsule returns a cylinder with hemispherical end caps.
- `solid.CellsFor(s *Solid, cellsPerMM float64) int` — CellsFor returns the cell count along the longest bounding-box axis for a given mesh density, floored at MinCells.
- `solid.ChamferMin(k float64) MinFunc` — ChamferMin returns a min function that produces a 45° chamfer of size k at the union seam.
- `solid.Cone(height, r0, r1, round float64) *Solid` — Cone returns a truncated cone of the given height with bottom radius r0 and top radius r1, centered at the origin and oriented along Z. Pass r1=0 for a tip; r0==r1 reduces to a cylinder.
- `solid.Cylinder(height, radius, round float64) *Solid` — Cylinder returns a cylinder of the given height and radius, centered at the origin and oriented along Z. round adds a fillet of that radius where the cylindrical surface meets the end caps; pass 0 for sharp edges.
- `solid.ExpMin(k float64) MinFunc` — ExpMin returns an exponential smooth min with strength k.
- `solid.Extrude(profile sdf.SDF2, height float64) *Solid` — Extrude linearly extrudes a 2D profile to a solid of the given height.
- `solid.ExtrudeRounded(profile sdf.SDF2, height, round float64) *Solid` — ExtrudeRounded extrudes a 2D profile with rounded edges.
- `solid.Gyroid(scale v3.Vec) *Solid` — Gyroid returns an infinite gyroid surface with the given period scale per axis.
- `solid.Identity3d() M44` — Identity3d returns the 4x4 identity matrix.

### validate — Geometry checks for tests: probes, mesh stats, printability.

Constants and variables:
- `validate.LeftHand` — LeftHand rises along +Z while turning clockwise seen from +Z.
- `validate.RightHand` — RightHand rises along +Z while turning counter-clockwise seen from +Z.
- `validate.Unknown` — Unknown means the two screw-invariance errors were too close to call.

Functions:
- `validate.At(s *solid.Solid, p v3.Vec) float64` — At returns the signed distance field of s at p: negative inside material, positive in air, zero on the surface.
- `validate.ChangedRegion(a, b *solid.Solid, cellsPerMM, tol float64) (v3.Box, int)` — ChangedRegion returns the bounding box of every surface point of either solid (sampled at cellsPerMM) at which the other solid's field exceeds tol in magnitude — that is, where a and b actually differ — together with the number of such points.
- `validate.Clearance(a, b *solid.Solid, cellsPerMM float64) Gap` — Clearance samples a's surface at cellsPerMM and reads b's signed field at every one of those points: Min is the worst clearance in mm (negative means a penetrates b).
- `validate.ClearanceIn(a, b *solid.Solid, region v3.Box, cellsPerMM float64) Gap` — ClearanceIn is Clearance restricted to the surface points of a that lie inside region (an axis-aligned box in world coordinates) — the way to ask about one feature of a big part without meshing it differently.
- `validate.Components(s *solid.Solid, cellsPerMM float64) int` — Components counts the connected bodies in s's rendered mesh at cellsPerMM: triangles that share a vertex belong to the same body.
- `validate.Compose(a, b []Pose) []Pose` — Compose returns the cartesian product of two pose families: len(a)*len(b) poses, each applying an a pose FIRST and then a b pose (b.Mul(a)), in a-major order — "for every bore shift, the whole screw travel".
- `validate.Congruent(a, b *solid.Solid, cellsPerMM, tol float64) (ab, ba Gap, ok bool)` — Congruent reports whether a and b occupy the same surface: ab reads b's field on a's surface, ba reads a's field on b's surface, and ok is true when the 95th percentile of |field| is within tol mm in BOTH directions.
- `validate.Coupon(s, keep *solid.Solid, cellsPerMM float64) *solid.Solid` — Coupon cuts a printable test piece out of s: the intersection of s with keep, dropped so its minimum Z is 0 (sitting on the plate).
- `validate.Cyl(r, deg, z float64) v3.Vec` — Cyl returns the point at radius r, angle deg (degrees, counter-clockwise from +X seen from +Z) and height z: the cylindrical coordinate most probes on turned or patterned parts are written in.
- `validate.DeviationSTL(path string, s *solid.Solid) (Gap, error)` — DeviationSTL measures an already-written mesh file against the solid it was rendered from: it reads the STL at path (binary or ASCII), deduplicates the vertices, and reports |field of s| at each one.
- `validate.Dimples(s *solid.Solid, n int, at, normal, along v3.Vec, dia, depth, spacing float64) *solid.Solid` — Dimples returns s with n small blind cylinders cut into the face at `at`, sunk along -normal to depth `depth` and spaced `spacing` apart along `along`, centred on `at`.
- `validate.FitCheck(dir, name string, parts []Part, point, normal v3.Vec, cellsPerMM float64) (map[string]Gap, error)` — FitCheck writes an inspection set for an assembly and reports every pairwise clearance.
- `validate.Gradient(s *solid.Solid, p v3.Vec) v3.Vec` — Gradient returns the unit surface normal direction of the field at p by central differences: the direction in which the field increases, which on the surface points out of the material.
- `validate.GridPoints(box v3.Box, step float64) []v3.Vec` — GridPoints returns a regular grid of points filling box at spacing step mm, starting at box.Min and including box.Max on any axis whose size is a whole multiple of step.
- `validate.HelixHand(s *solid.Solid, pitch, cellsPerMM float64) HandResult` — HelixHand decides the hand of a helical solid of the given axial pitch (mm of rise per full turn about Z, always positive) by screw invariance: it samples the surface at cellsPerMM, advances each point by d = pitch/8 along +Z while rotating it +360*d/pitch (right-hand) and -360*d/pitch (left-hand), and returns the hand whose p95 |field| is smaller, with both errors.
- `validate.Identical(a, b *solid.Solid, pts []v3.Vec, tol float64) IdentityResult` — Identical reports whether a and b have the same signed distance field at every point of pts within tol mm.
- `validate.In(name string, p v3.Vec) Probe` — In returns a Probe expecting p to be inside material (At < 0).
- `validate.Inside(s *solid.Solid, p v3.Vec) bool` — Inside reports whether p is inside the material of s (At(s, p) < 0).
- `validate.IsWatertight(tris []mesh.Triangle3) (bool, int)` — IsWatertight reports whether the mesh is a closed surface and the boundary-edge count (0 = sealed).
- `validate.LinearPoses(dir v3.Vec, from, to, step float64) []Pose` — LinearPoses returns pure translations of the moving body along the unit direction of dir, by from, from+step, ...
- `validate.Manifest(parts []Part, cellsPerMM float64) string` — Manifest summarises parts as a markdown table — name, bounding-box min and max, size, volume and body count — for a build log, a PR comment, or a model deciding whether the part it just wrote is the size it meant.
- `validate.MinWall(s *solid.Solid, region v3.Box, step, max float64) WallReport` — MinWall scans region on a grid of `step` mm and reports the thinnest material run found through any interior grid point along each of the three axes, searching at most max mm either side.
- `validate.Of(s *solid.Solid, cellsPerMM float64) Stats` — Of computes validation stats by rendering s at cellsPerMM density.
- `validate.OfMesh(tris []mesh.Triangle3) Stats` — OfMesh computes validation stats from a precomputed triangle mesh.
- `validate.Opening(s *solid.Solid, p, dir v3.Vec, max float64) (float64, bool)` — Opening measures the clear void span (mm) through p along ±dir: p must be in air (At >= 0), and the result is the distance between the two material surfaces found within max mm either side.
- `validate.Out(name string, p v3.Vec) Probe` — Out returns a Probe expecting p to be in air (At > 0).
- `validate.OverhangArea(tris []mesh.Triangle3, maxAngleDeg float64) float64` — OverhangArea returns the total area of triangles whose downward-facing normal makes an angle greater than maxAngleDeg from vertical (Z+).
- `validate.OverhangFaces(tris []mesh.Triangle3, maxAngleDeg float64) []mesh.Triangle3` — OverhangFaces returns the triangles overhanging more than maxAngleDeg — useful for visualizing problem areas (write them to their own STL and load alongside the part).
- `validate.Overhangs(s *solid.Solid, cellsPerMM float64, o OverhangOptions) OverhangReport` — Overhangs audits s for unsupported overhangs at mesh density cellsPerMM, in the solid's current frame (minimum Z is the build plate).
- `validate.Percentile(xs []float64, q float64) float64` — Percentile returns the q-th percentile (0..100) of xs by nearest rank on a sorted copy; NaN for an empty slice.
- `validate.Probes(s *solid.Solid, probes []Probe) []ProbeResult` — Probes evaluates every probe against s in parallel and returns one result per probe, in the same order.
- `validate.ProbesIn(solids map[string]*solid.Solid, probes []NamedProbe) []ProbeResult` — ProbesIn evaluates each NamedProbe against solids[probe.Solid] and returns results whose Name is "solid:name".
- `validate.RequireBounds(t testing.TB, s *solid.Solid, want v3.Box, tol float64)` — RequireBounds calls t.Errorf if s's bounding box corners differ from want by more than tol mm in any component.
- `validate.RequireClearance(t testing.TB, a, b *solid.Solid, cellsPerMM, minGap float64)` — RequireClearance fails the test unless every surface point of a is at least minGap mm clear of b's material (g.Min >= minGap).
- `validate.RequireCongruent(t testing.TB, a, b *solid.Solid, cellsPerMM, tol float64)` — RequireCongruent fails the test unless a and b describe the same surface within tol mm (see Congruent).
- `validate.RequireHelixHand(t testing.TB, s *solid.Solid, pitch, cellsPerMM float64, want Hand)` — RequireHelixHand fails the test unless HelixHand decides s winds the way want does — the guard against a mirrored thread shipping as a right-hand one.
- `validate.RequireIdentical(t testing.TB, a, b *solid.Solid, pts []v3.Vec, tol float64)` — RequireIdentical compares the two fields at pts, logs the report line, and calls t.Errorf if any point differs by more than tol mm (or if pts is empty, which would otherwise pass vacuously).
- `validate.RequireInterference(t testing.TB, a, b *solid.Solid, cellsPerMM, atLeast float64)` — RequireInterference fails the test unless a penetrates b by at least atLeast mm somewhere (g.Min <= -atLeast).
- `validate.RequireMaxOverhang(t *testing.T, s *solid.Solid, cellsPerMM, maxAngleDeg float64, tinyArea ...float64)` — RequireMaxOverhang fails the test if any face overhangs more than maxAngleDeg — i.e. the part would need supports when FDM-printed in default Z-up orientation.
- `validate.RequireMinWall(t testing.TB, s *solid.Solid, region v3.Box, step, max, wantMin float64)` — RequireMinWall runs MinWall over region and calls t.Errorf if the thinnest material run found is below wantMin mm, or if the region contained no interior sample at all (which would otherwise pass vacuously).
- `validate.RequireNear(t testing.TB, name string, got, want, tol float64)` — RequireNear logs "name = got (want w ± tol)" and calls t.Errorf when |got-want| > tol — the standard dimension assertion for measurements read back out of a solid with SurfaceR, SurfaceZ, Opening or WallThickness.
- `validate.RequireNoContact(t testing.TB, a, b *solid.Solid, cellsPerMM float64)` — RequireNoContact fails the test unless a's surface is strictly outside b everywhere (g.Min > 0): the two bodies do not touch at the sampled density.
- `validate.RequireOneBody(t testing.TB, s *solid.Solid, cellsPerMM float64)` — RequireOneBody fails the test when s renders as anything other than a single connected body at cellsPerMM — the guard against a boolean that quietly severed a part, or a cut that left an island.
- `validate.RequireOverhangArea(t testing.TB, s *solid.Solid, cellsPerMM float64, o OverhangOptions, areaBudget float64)` — RequireOverhangArea logs the audit and fails the test when the unsupported over-threshold area exceeds areaBudget (mm²).
- `validate.RequireProbes(t testing.TB, s *solid.Solid, probes []Probe)` — RequireProbes evaluates probes against s, logs one report line per probe plus an "N/M probes passed" summary, and calls t.Errorf for every probe whose material state (or margin) was wrong.
- `validate.RequireProbesIn(t testing.TB, solids map[string]*solid.Solid, probes []NamedProbe)` — RequireProbesIn evaluates a multi-solid probe table, logs one report line per probe plus an "N/M probes passed" summary, and calls t.Errorf for every failure.
- `validate.RequireStandsOn(t testing.TB, s *solid.Solid, z, tol float64)` — RequireStandsOn calls t.Errorf unless the minimum Z of s's bounding box is within tol mm of z — the print-plate assertion, normally z = 0, that catches a part left floating or sunk after a transform.
- `validate.RequireSweepBlocked(t testing.TB, moving, fixed *solid.Solid, poses []Pose, cellsPerMM, atLeast float64)` — RequireSweepBlocked fails the test unless the moving body collides with the fixed body by at least atLeast mm somewhere in the motion (r.Min <= -atLeast).
- `validate.RequireSweepClear(t testing.TB, moving, fixed *solid.Solid, poses []Pose, cellsPerMM, minClear float64)` — RequireSweepClear fails the test unless the moving body stays at least minClear mm away from the fixed body at every pose (r.Min >= minClear).
- `validate.RequireUnchangedOutside(t testing.TB, before, after *solid.Solid, region v3.Box, cellsPerMM, tol float64)` — RequireUnchangedOutside calls t.Errorf if any surface point of `before` or `after` that lies outside `region` reads further than tol mm from the other solid's surface — the assertion that an edit only moved geometry inside the region it was supposed to touch.
- `validate.RequireVolumeNear(t *testing.T, s *solid.Solid, cellsPerMM, expectedMM3, relTol float64)` — RequireVolumeNear fails the test if the rendered solid's volume differs from expected by more than relTol (e.g. 0.02 = 2%).
- `validate.RequireWatertight(t *testing.T, s *solid.Solid, cellsPerMM float64)` — RequireWatertight fails the test if the rendered mesh has any boundary edges.
- `validate.RotationPoses(axis v3.Vec, from, to, step float64) []Pose` — RotationPoses returns rotations of the moving body about the line through the origin along axis, by from, from+step, ...
- `validate.ScrewPoses(step, total, lead float64) []Pose` — ScrewPoses returns the poses of a screw motion about +Z: at each angle deg = 0, step, 2*step ...
- `validate.Surface(s *solid.Solid, cellsPerMM float64) []v3.Vec` — Surface returns points lying on the surface of s: the deduplicated vertices of a marching-cubes mesh at cellsPerMM.
- `validate.SurfaceAlong(s *solid.Solid, from, dir v3.Vec, maxDist, step float64) (float64, bool)` — SurfaceAlong marches from `from` along dir (normalised here) in steps of `step` mm (0 means 0.1) up to maxDist mm, until the sign of the field changes, then bisects that interval to 1e-6 mm.
- `validate.SurfaceArea(tris []mesh.Triangle3) float64` — SurfaceArea returns the total area of all triangles in mm².
- `validate.SurfaceR(s *solid.Solid, deg, z, rMin, rMax float64) (float64, bool)` — SurfaceR returns the radius (mm) at which a surface is met when marching outward from the Z axis at angle deg (degrees counter-clockwise from +X seen from +Z) and height z, starting at radius rMin and stopping at rMax.
- `validate.SurfaceZ(s *solid.Solid, x, y, zTop, zBottom float64) (float64, bool)` — SurfaceZ returns the height (mm) of the first surface met marching down (-Z) from (x, y, zTop) to zBottom — the top surface of the solid at that plan-view point.
- `validate.Sweep(moving, fixed *solid.Solid, poses []Pose, cellsPerMM float64) SweepResult` — Sweep samples moving's surface at cellsPerMM once, transforms those points by each pose, and reads fixed's signed field at every transformed point.
- `validate.Vertices(tris []mesh.Triangle3) []v3.Vec` — Vertices returns the deduplicated vertices of a triangle mesh.
- `validate.Volume(tris []mesh.Triangle3) float64` — Volume returns the enclosed volume in mm³, computed as the sum of signed tetrahedron volumes from the origin.
- `validate.WallThickness(s *solid.Solid, p, dir v3.Vec, max float64) (float64, bool)` — WallThickness measures the material run (mm) through p along ±dir: p must be inside material (At < 0), and the result is the distance between the two surfaces found within max mm either side.

`validate.Gap` — Gap describes how one solid's surface sits relative to another solid's field: every sampled value is the second solid's signed field (mm) at a surface point of the first.
- `.String() string` — String renders the gap as one test-log line: worst and best readings with the points they occurred at, plus the median and 95th percentile.

`validate.Hand` — Hand is the handedness of a helical feature about the +Z axis.
- `.String() string` — String returns "right-hand", "left-hand" or "unknown".

`validate.HandResult` — HandResult reports which hand won the screw-invariance test and by how much: RightErr and LeftErr are the 95th percentiles of |field| (mm) after applying the right-hand and left-hand screw transform to N surface points.
